# Artiflow documentation

This directory holds Artiflow's repository-facing documentation: architecture
notes for contributors and operating notes that stay close to the code. The
user-facing documentation site lives in [`apps/web`](../apps/web/README.md)
(Astro + Starlight, served at `/docs`), and carries the quickstart, concepts,
guides, self-hosting and contributing paths.

## Published documentation site

The site is built from `apps/web`, mounted under `/docs` and English-only today.
Each file under `apps/web/src/content/docs/docs/` becomes a route in the
autogenerated sidebar, so a new page needs no configuration change:

| Section      | Covers                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------- |
| Start        | Quickstart: connect an agent, publish a first page, open and share it.                   |
| Connect      | The `/mcp` endpoint, OAuth, and the client configurations the dashboard offers.          |
| Concepts     | Artifacts, revisions, kinds, access model, URLs and limits.                              |
| Artifacts    | What HTML pages may run in the viewer, and how Markdown documents render and are edited. |
| Guides       | Editing and revision history; sharing, public links, revocation and deletion.            |
| Reference    | HTTP routes, the MCP tools, API authentication and configuration limits.                 |
| Self-hosting | Installation, configuration, verification, upgrades, backups and restore.                |
| Contributing | Development setup, code layout, tests and how to add a documentation page.               |

The site's own README explains its layout, commands and the OpenCode research
record: [`apps/web/README.md`](../apps/web/README.md). This directory stays the
source for architecture, flows and the local runbook; [`CONTRIBUTING.md`](../CONTRIBUTING.md)
is the entry point for contributors.

## Conventions used here

- **Artifact** — the logical object owned by a user (`artifacts` row).
- **Revision** — an immutable version of an artifact's bytes, stored under a key of its own.
- **Upload** — a bounded, resumable staging session that ends in a commit.
- **Owner** — the user whose `ownerId` matches the artifact; the only writer by default.
- **Reader/editor/commenter** — a registered recipient with a share grant role.
- **Control plane / data plane** — PostgreSQL metadata versus object-storage bytes.
